# Nexus Reader — หน้าเว็บอย่างเป็นทางการและพอร์ทัลดาวน์โหลด (`nexus.apk`)

หน้าเว็บอย่างเป็นทางการสำหรับ **Nexus (Nexus Reader)** แอปพลิเคชัน Android ดั้งเดิมที่พัฒนาด้วย **Kotlin** และ **Jetpack Compose (Material Design 3)** สำหรับการสำรวจมังงะ เว็บตูน และการ์ตูน พร้อมโหมดมืดอัตโนมัติ รายการโปรดและประวัติส่วนตัวในห้อง (Local SQLite) การแจ้งเตือน RSS ในพื้นหลังทุก 15 นาที และตัวตรวจสอบการอัปเดต

### สิทธิ์ที่ประกาศไว้ใน `AndroidManifest.xml`

- `INTERNET` และ `ACCESS_NETWORK_STATE`: การเรียกดูเว็บไซต์ในตัว, การอ่านฟีด RSS และการตรวจสอบการอัปเดต

- `POST_NOTIFICATIONS`: ร้องขอในขณะทำงานบน Android 13 ขึ้นไป เฉพาะเมื่อผู้ใช้เปิดใช้งานการแจ้งเตือน RSS เท่านั้น

- `RECEIVE_BOOT_COMPLETED`: เปิดใช้งานการตรวจสอบฟีด RSS เป็นระยะทุก 15 นาทีหลังจากอุปกรณ์รีสตาร์ท

**ไม่ขอสิทธิ์การเข้าถึงที่รุกล้ำ**: ไม่ขอสิทธิ์การเข้าถึงกล้อง ไมโครโฟน GPS หรือพื้นที่จัดเก็บข้อมูลจำนวนมาก

## การตรวจสอบความถูกต้องของ `nexus.apk`

ตรวจสอบขนาดและค่าแฮช SHA-256 ของไฟล์ไบนารีที่ลงนามแล้วก่อนที่จะแจกจ่ายหรือติดตั้ง:

```powershell
# Windows (PowerShell)
(Get-Item nexus.apk).Length
Get-FileHash nexus.apk -Algorithm SHA256
```

```bash
# Linux / macOS
ls -lh nexus.apk && sha256sum nexus.apk

# ใบรับรองการลงนาม
keytool -printcert -jarfile nexus.apk
```

## เวอร์ชันในอนาคตและขอบเขตของโครงการ

แนวคิดนั้นเรียบง่าย: ทำไมต้องมีแอปแยกต่างหากมากมายเพื่ออ่านการ์ตูนเรื่องโปรดของคุณ ในเมื่อคุณสามารถรวมทุกอย่างไว้ในที่เก็บข้อมูลเดียวที่มีผลงานมากกว่า 2 ล้านชิ้น อัปเดตทุกวันด้วยเนื้อหาใหม่ๆ ได้?

กำลังดำเนินการทดสอบการรับโหลดและความเครียดของเซิร์ฟเวอร์เพื่อวางแผนการพัฒนาที่ดีที่สุดสำหรับโครงการนี้ ซึ่งเริ่มต้นจากการเข้าถึงการ์ตูนเพียงไม่กี่พันเรื่อง และในที่สุดจะขยายไปสู่การ์ตูนหลายล้านเรื่องที่พร้อมให้ผู้อ่านอ่านออนไลน์หรือดาวน์โหลดในรูปแบบ PDF หรือ CBR
