# Nexus Reader — Официальная целевая страница и портал загрузки (`nexus.apk`)

Официальная целевая страница **Nexus (Nexus Reader)**, нативного приложения для Android, разработанного на **Kotlin** и **Jetpack Compose (Material Design 3)** для просмотра манги, вебтунов и комиксов, с автоматическим темным режимом, личными избранными и историей в комнате (локальная SQLite), фоновыми RSS-уведомлениями каждые 15 минут и проверкой обновлений.

### Разрешения, объявленные в `AndroidManifest.xml`

- `INTERNET` и `ACCESS_NETWORK_STATE`: встроенный просмотр веб-страниц, чтение RSS-лент и проверка обновлений.

- `POST_NOTIFICATIONS`: запрашивается во время выполнения на Android 13+ только если у пользователя включены RSS-уведомления. — `RECEIVE_BOOT_COMPLETED`: Повторно активирует периодическую проверку RSS-ленты каждые 15 минут после перезагрузки устройства.

**Без навязчивых разрешений**: Не запрашивает доступ к камере, микрофону, GPS или расширенному хранилищу.

## Проверка целостности `nexus.apk`

Проверка размера и хеша SHA-256 подписанного бинарного файла перед его распространением или установкой:

```powershell
# Windows (PowerShell)
(Get-Item nexus.apk).Length
Get-FileHash nexus.apk -Algorithm SHA256
```

```bash
# Linux / macOS
ls -lh nexus.apk && sha256sum nexus.apk

# Подписание сертификата
keytool -printcert -jarfile nexus.apk
```

## Будущие версии и область применения проекта

Идея проста: зачем иметь десятки отдельных приложений для чтения любимых комиксов, когда можно объединить все в одном репозитории с более чем 2 миллионами работ, ежедневно обновляемых новым материалом?

Проводятся нагрузочные и стресс-тесты серверов для разработки оптимального плана развития этого проекта, который начинался с предоставления доступа к нескольким тысячам комиксов и в конечном итоге расширится до миллионов публикаций, готовых к чтению онлайн или загрузке в формате PDF или CBR.
